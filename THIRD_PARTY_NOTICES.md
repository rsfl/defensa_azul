## Detection Skills

The `ctf-detection-triage` skill is an adapted and modified work informed by the following Detection Skills from CDESpace/Detection-Skills at commit `790ebc6dbb64469d4aac6cbe7199c56e8bf157bf`:

- Network Exposed Service Exploitation
- Application Web App Exploitation
- Endpoint Execution Payload Delivery
- Endpoint Defense Evasion Tampering
- Application Control Policy Tampering
- Cloud Container Workload Control Plane

Upstream authorship is attributed to Vega Security. The upstream repository is licensed under the Apache License 2.0: <https://github.com/CDESpace/Detection-Skills/blob/main/LICENSE>.

The Defensa Azul adaptation changes the decision contract and procedures for an intentionally vulnerable CTF, adds flag/fairness and evidence-redaction constraints, and removes environment-specific assumptions that are not supported by the deployed sensors.
