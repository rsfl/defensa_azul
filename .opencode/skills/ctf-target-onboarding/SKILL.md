# Defensive workflow

Record operator-supplied target and instance identifiers, service and network scope, expected behavior, health checks, and sensor mappings. Begin in observe mode. Enforcement requires explicit authorization, a narrow action allowlist, confidence threshold, TTL, tested rollback, and service checks. Do not put credentials, personal data, or raw exploit content in profiles. Do not deploy or restart a target without separate authorization.
