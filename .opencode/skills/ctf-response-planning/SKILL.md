# Defensive workflow

Read incident evidence, target configuration, and policy. Prefer the least disruptive action that improves visibility or addresses confirmed harm. A proposal is not authorization. Include target, resource, evidence, confidence, TTL, rollback, expected effect, operational impact, and health checks. If authorization or evidence is incomplete, recommend further observation.
